# 🔭 Argus

Sistema de monitoramento e análise do uso de computadores em ambientes corporativos.

O **Argus** tem como objetivo centralizar informações sobre utilização de computadores, aplicativos, sites, tempo de uso, produtividade e recursos, oferecendo uma interface moderna para acompanhamento e análise.

> 🚧 **Projeto em desenvolvimento — nova versão em React + TypeScript.**

## 🎯 Objetivo

Criar uma plataforma que permita visualizar e acompanhar informações relacionadas ao uso dos computadores de uma empresa de forma organizada, visual e intuitiva.

Principais objetivos:

* Monitoramento de computadores
* Visualização de dados
* Acompanhamento de produtividade
* Gerenciamento de usuários
* Gerenciamento de dispositivos
* Configurações da plataforma
* Planos e recursos do sistema

## 🖥️ Frontend

O frontend é responsável pela interface e experiência de uso do Argus.

A nova versão está sendo desenvolvida utilizando:

* React
* TypeScript
* Vite
* React Router
* Lucide React
* CSS
* ESLint

O frontend será preparado para integração com uma API desenvolvida separadamente.

## 🎨 Interface

A identidade visual do Argus segue uma proposta:

* Dark
* Moderna
* Tecnológica
* Institucional
* Minimalista
* Focada em visualização de dados

A interface utiliza tons escuros, detalhes em roxo/violeta, cards, efeitos sutis e elementos de destaque.
